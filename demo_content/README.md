# C.A.P.I.T.O.L. Demo Content

This folder contains sample legislative documents for testing and demonstration purposes.

## How to Use

1. **Ingestion**: 
   - Open C.A.P.I.T.O.L.
   - Go to the **Ingestion** tab.
   - Click "Browse Folder" and select this `demo_content` directory.
   - Click "Import & Process".

2. **Analysis**:
   - Go to **The Vault** to see the imported documents.
   - Use **The Oracle** to ask questions like:
     - "What are the main provisions of the urban planning bill?"
     - "Summarize the renewable energy incentives."
   - Use **Minerva's Forge** to generate an Executive Summary for the "Future Transportation Act".

## Included Documents

- **Bill AB-2026**: Future Transportation & Urban Mobility Act
- **Bill SB-101**: Renewable Energy Infrastructure incentives
- **Resolution 55**: AI Ethics in Public Governance

## Note for Distribution

When packaging the app, this folder can be included as a separate download or bundled with the installer to help new users get started immediately.
