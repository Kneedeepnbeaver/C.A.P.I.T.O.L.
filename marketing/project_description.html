C.A.P.I.T.O.L.

Civic Artificial Programming & Intelligence for Tracking, Organizing & Lawmaking

A powerful productivity tool designed for Legislative Professionals. Analyze documents, track bills, and generate insights using advanced local RAG technology.

📄 Smart Ingestion

Seamlessly import and process legislative PDFs and documents with automated text extraction and indexing.

  • Multi-format support: PDFs, text files, markdown, WebVTT transcripts
  • Intelligent metadata extraction (bill numbers, dates, sponsors)
  • Batch processing for multiple documents
  • Automatic text extraction and structure parsing

🗄️ The Vault

Securely store, organize, and manage your analyzed documents in a searchable, local database.

  • Full-text search across all documents
  • Advanced filtering by date, type, keywords, or metadata
  • Local storage—your data never leaves your machine
  • Export options in multiple formats

🔮 The Oracle

Ask complex questions about your bills and receive immediate, citation-backed answers from your local AI.

  • Natural language queries in plain English
  • Citation-backed answers with source links
  • Comparative analysis across multiple documents
  • Conversational interface for follow-up questions

✍️ Minerva's Forge

Generate executive summaries, press releases, and social media content automatically from your documents.

  • Executive Summaries for quick briefings
  • Press Releases with professional formatting
  • Talking Points (pro/con arguments)
  • Committee Briefings, Policy Analysis, and Social Media Suites

🔒 Privacy & Security

Local-First Architecture

Your documents never leave your computer. Everything runs locally for maximum privacy and security.

  • No Cloud Required: Everything runs on your computer
  • No Data Transmission: Your documents stay private
  • Local LLM: AI processing happens on your machine
  • Offline Capable: Works without internet connection
  • Open Source: MIT License—audit the code yourself

🍎 macOS Installation & Unquarantine

Why Unquarantine? macOS Gatekeeper may quarantine downloaded applications from unidentified developers. Since C.A.P.I.T.O.L. is distributed under the MIT License, you'll need to unquarantine it.

Method 1: Terminal (Recommended)
  1. Open Terminal (Applications → Utilities → Terminal, or press Cmd + Space and type "Terminal")
  2. Navigate to your Downloads folder:
    cd ~/Downloads
  3. Unquarantine the DMG file:
    xattr -d com.apple.quarantine C.A.P.I.T.O.L.-*.dmg
  4. Open the DMG:
    open C.A.P.I.T.O.L.-*.dmg
    Or simply double-click the DMG file in Finder.
  5. Drag C.A.P.I.T.O.L.app from the DMG window to your Applications folder
  6. Unquarantine the installed app:
    xattr -d com.apple.quarantine /Applications/C.A.P.I.T.O.L.app
  7. Launch the app. If you see a security warning, right-click the app and select "Open", then click "Open" in the dialog
Method 2: System Settings
  1. Open System Settings → Privacy & Security
  2. Look for: "C.A.P.I.T.O.L. was blocked"
  3. Click "Open Anyway" or "Allow"
  4. Confirm by clicking "Open" in the dialog
Method 3: Right-Click Open
  1. Navigate to /Applications/C.A.P.I.T.O.L.app
  2. Right-click (or Control-click) the app
  3. Select "Open" from the context menu
  4. Click "Open" in the security dialog
macOS: "App is damaged and can't be opened"

Solution:

xattr -cr /Applications/C.A.P.I.T.O.L.app

This removes all extended attributes (including quarantine) from the app.

🪟 Windows Installation

  1. Download the installer from GitHub Releases
  2. Run the installer (C.A.P.I.T.O.L.-[version]-win-x64.exe)
  3. Follow the installation wizard
  4. Launch C.A.P.I.T.O.L. from the Start menu or desktop shortcut
Note: Windows Defender or antivirus software may flag the app. This is common for unsigned applications. You may need to click "More info" on the warning screen and select "Run anyway", or add an exception in Windows Defender settings.

🐧 Linux Installation

  1. Download the AppImage from GitHub Releases
  2. Make it executable:
    chmod +x C.A.P.I.T.O.L.-[version]-x86_64.AppImage
  3. Run the app:
    ./C.A.P.I.T.O.L.-[version]-x86_64.AppImage

Optional: To integrate with your system, move the AppImage to ~/Applications or /opt and create a desktop entry for easier launching.

🆘 Troubleshooting

App won't launch / Crashes on startup
  1. Check that you have the required Python runtime (if using local LLM)
  2. Ensure you have sufficient disk space
  3. Check the console logs:
    • macOS: Open Console.app and filter for "C.A.P.I.T.O.L"
    • Windows: Check Event Viewer
    • Linux: Check ~/.config/C.A.P.I.T.O.L/logs/
Python backend not found? The app includes a bundled Python backend. If you see errors about missing Python, ensure the app was installed correctly (not just copied), re-download and reinstall from the DMG/installer, and check that the app bundle is intact.
